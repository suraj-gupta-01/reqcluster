Additional Guardrails Active:
  • Fan-Out Capping (MAX_PAIRS_PER_ARTIFACT = 400): Prevents over-shared generic terms from quadratically expanding into thousands of spurious edges.
  • Ragged Array Recovery: Recovers automatically when input arrays contain missing or irregular requirement IDs without throwing IndexError.
  • Topological Cycle Breaker (DFS + Kahn): Breaks back-edges with lowest weights to guarantee a strictly acyclic prerequisite DAG.
